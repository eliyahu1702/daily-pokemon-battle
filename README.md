# Daily Pokémon Battle

A playable Pokémon romhack built around a daily challenge.

## The idea

- **Draft a team of six.** Pick your squad from Pokémon across every generation.
- **Fight a new battle every day.** Each day brings a different opponent and setup, so there's always a fresh challenge.

## Status

Early planning. The base game (the ROM or decomp the hack builds on) hasn't been chosen yet, so there's no game code here so far.
